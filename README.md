# 100-Day Roadmap

## Target

Become capable of building, testing, explaining and improving practical
Python-based AI applications.

  -----------------------------------------------------------------------
  Days                    Focus                   Evidence
  ----------------------- ----------------------- -----------------------
  1--5                    Intermediate Python     CLI task tracker

  6--9                    NumPy and Pandas        Data cleaning notebook

  10--12                  EDA, visualisation,     Analysis
                          Power BI                report/dashboard

  13--16                  HTTP, REST, FastAPI,    Tested CRUD API
                          Pydantic                

  17--20                  SQL, PostgreSQL,        Database-backed API
                          SQLAlchemy              

  21--30                  Practical ML            Scikit-learn pipeline
                          fundamentals            

  31--45                  NLP, embeddings,        Token and local-model
                          transformers            experiments

  46--70                  LLMs, RAG, LangChain,   Document Q&A and
                          LangGraph, agents       stateful workflow

  71--85                  AI applications         Research assistant +
                                                  task agent

  86--100                 Deployment, tests,      Documented portfolio
                          portfolio, interviews   
  -----------------------------------------------------------------------

## Daily intermediate pace

-   60 min reading/concepts.
-   75 min coding.
-   30 min job applications.
-   15 min revision. Adjust on busy workdays; a short session is better
    than abandoning the routine.

## Day-by-day topics

### Days 1--5: Python

1.  Collections, mutability.
2.  Comprehensions, sorting, unpacking.
3.  Functions, scope, `*args`, `**kwargs`, type hints.
4.  OOP, composition, inheritance, dataclasses.
5.  Exceptions, files, modules, iterators, generators, context managers.

### Days 6--12: Data

6.  NumPy arrays, shapes, dtypes, indexing.
7.  Broadcasting and vectorisation.
8.  Pandas Series/DataFrames, selection and filtering.
9.  Cleaning, missing values, joins, groupby, dates.
10. Matplotlib and Seaborn.
11. EDA, distributions, summary statistics, correlation.
12. Power BI import, Power Query, relationships, visuals, basic DAX.

### Days 13--20: APIs and databases

13. HTTP, JSON, REST, methods and status codes.
14. FastAPI routes, Pydantic and validation.
15. CRUD, error handling, Postman and tests.
16. API project structure and dependencies.
17. SQL filtering, aggregation and joins.
18. CTEs, subqueries, window functions, indexes basics.
19. Python database connectivity and SQLAlchemy.
20. Integrate API + database; review.

### Days 21--30: Practical ML

21. ML workflow, supervised/unsupervised, features/labels.
22. Train/validation/test split, leakage and baselines.
23. Linear and logistic regression.
24. Decision trees and random forests.
25. Gradient boosting and LightGBM/XGBoost overview.
26. KNN and SVM; scaling.
27. K-Means and DBSCAN.
28. Anomaly detection and imbalanced data.
29. Metrics: confusion matrix, precision, recall, F1, ROC-AUC.
30. End-to-end scikit-learn pipeline and model persistence.

### Days 31--45: LLM foundations

31. NLP overview.
32. Tokenisation and token IDs.
33. Context windows and token budgets.
34. Embeddings and semantic similarity.
35. Vector representations and similarity search.
36. Next-token prediction.
37. Attention intuition.
38. Self-attention and multi-head attention.
39. Positional information and transformer blocks.
40. Encoder-only, decoder-only, encoder-decoder.
41. GPT-style models and inference.
42. Pretraining, instruction tuning, fine-tuning.
43. Hugging Face pipelines and model cards.
44. Ollama local model experiments.
45. Build a simple text assistant with a model adapter.

### Days 46--70: RAG and agents

46. LLM application architecture and provider adapters.
47. Prompt design and constraints.
48. Structured output and validation.
49. Document ingestion.
50. Chunking and metadata.
51. Embeddings and storage.
52. Vector databases and similarity search.
53. Retrieval and top-k.
54. Context construction and citations.
55. RAG baseline.
56. Retrieval/answer quality and failure cases.
57. Hybrid search and reranking concepts.
58. RAG evaluation and prompt injection.
59. LangChain model interfaces.
60. Prompts, parsers, retrievers.
61. Tools and schemas.
62. LangGraph state and nodes.
63. Edges and conditional routing.
64. Checkpointing and persistence.
65. Human approval steps.
66. Agent loops and bounded execution.
67. Conversation state vs knowledge memory.
68. Multi-step workflow with tools.
69. Evaluation, tracing, retries and timeouts.
70. Mini-project: stateful research workflow.

### Days 71--85: Applications

71--77. AI Research Assistant: ingestion, retrieval, citations, API,
tests and evaluation. 78--84. Task Automation Agent: tools, graph state,
approval gates, audit log and tests. 85. Portfolio review, architecture
diagrams and demo.

### Days 86--100: Delivery and interviews

86. Docker images and Dockerfiles.
87. Compose for API/database/vector store.
88. Deploy a small API safely.
89. Secrets, config, logging and errors.
90. Unit and integration tests.
91. Observability, tracing, latency and cost.
92. Security, prompt injection and least privilege.
93. GitHub portfolio cleanup.
94. Python interview revision.
95. SQL/API interview revision.
96. ML/LLM concepts.
97. RAG/agent architecture.
98. Project walkthrough mock interview.
99. Resume and applications review.
100. Final assessment and next plan.

## Job applications every week

Aim for 15--20 relevant applications, 5 referral requests, 5--10
recruiter connections, one mock interview and a weekly review. Quality
matters more than random volume.

## Completion rule

Explain the idea in your own words, implement it, solve an exercise,
commit meaningful work, and record remaining questions.
